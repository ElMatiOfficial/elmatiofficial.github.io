# Sebastian Mateus — Portfolio

Personal portfolio site: ML engineer & AI researcher — agent security, LLM evaluation,
mathematical reasoning.

Hand-built static site: one HTML file, one stylesheet, one small script. No frameworks,
no build step.

## Local preview

```bash
python -m http.server 8321
```

Then open http://localhost:8321.

## Deploy (GitHub Pages)

Push this repo to GitHub, then Settings → Pages → Deploy from branch → `main` / root.
For a `https://<user>.github.io/` root URL, name the repo `<user>.github.io`.
